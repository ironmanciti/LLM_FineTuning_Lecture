# data/ — 강사 관리 데이터

## `regression_set.jsonl` — 회귀 세트 20문항 (**강사 편집 필수**)

3일차 5교시(§3.12-8) 「회귀 점검 — 무엇이 나빠졌는가」와 실습 `430`에서 사용한다.
파인튜닝으로 **목표 태스크는 올랐는데 다른 능력이 퇴화**하는 현상을 잡는 세트다.

| 범주 | 문항 수 | 무엇을 보는가 |
|---|---|---|
| 일반상식 | 5 | 기본 지식 유지. 한국어 고유 지식(cs-04)이 먼저 깨진다 |
| 간단추론 | 5 | 2단계 산술·순서 추론. 소형 모델에서 가장 취약 |
| 형식지시 | 5 | JSON SFT가 **다른 형식 지시를 덮어쓰지 않았는가** |
| 안전응답 | 5 | 거절·불확실성 표현 유지. sf-04(환각 저항)가 핵심 |

### 왜 강사가 편집해야 하는가

1. **수강생이 만들면 학습 데이터와 겹친다.** 회귀 세트는 학습에 절대 쓰이지 않아야 한다.
2. **이 20문항은 초안이다.** 기수의 도메인에 맞게 5~10문항을 교체하면 진단력이 올라간다.
3. **`check` 규칙이 기수마다 맞지 않을 수 있다.** 개강 전 베이스 모델로 1회 돌려
   **베이스가 이미 틀리는 문항은 제거하거나 쉽게 고칠 것** — 베이스가 못 하는 것은
   퇴화가 아니므로 회귀 지표를 오염시킨다.

### `check` 규칙 형식

| type | 필드 | 판정 |
|---|---|---|
| `contains_any` | `values` | 응답에 값 중 하나라도 포함되면 통과 (정규화 후 비교) |
| `regex` | `pattern` | 정규식 매치되면 통과 |
| `max_sentences` | `value` | 문장 수가 값 이하면 통과 |
| `refusal` | — | 거절·불확실성 표현이 있으면 통과. **부분 자동 판정이므로 사람이 검수할 것** |

`refusal`은 키워드 기반이라 오판이 난다. `430` 노트북이 해당 문항의 응답 전문을
출력하도록 되어 있으니 **강사가 육안으로 확인**하고 필요하면 점수를 수정한다.

### 개강 전 체크리스트

- [ ] 베이스 모델로 `430`의 회귀 파트만 1회 실행
- [ ] 베이스 점수가 20문항 중 15문항 이상 통과하는지 확인 (미달 시 문항 난이도 하향)
- [ ] `refusal` 5문항의 베이스 응답을 육안 검수하고 키워드 목록 보정
- [ ] 기수 도메인에 맞춰 5문항 교체
